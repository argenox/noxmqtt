# Project

NoxMQTT is the MQTT client product identity for the `noxmqtt` repository.

## Scope

The project aims to deliver:

- a compact C MQTT client for embedded use
- strong MQTT 3.1.1 and MQTT 5 support
- reusable transport layering
- secure connectivity through application-chosen TLS backends
- practical integration on Windows and ESP-IDF first

## Roadmap themes

- complete MQTT 5 coverage and interoperability
- full transport/TLS reuse across platforms
- stronger automated interop coverage against real brokers
- cleaner component packaging for embedded platforms

## Naming note

The codebase and some source paths still use `noxmqtt`. This documentation site presents the product as `NoxMQTT`.
